Version

0.1 (Arbeitsversion)

⸻

1. Projektvision

Ziel

Entwicklung einer modernen Web-Anwendung für ein privates Fußball-Managerspiel, das auf einem modifizierten Regelwerk des kicker Interactive Managers basiert.

Die Anwendung ersetzt die bisherige, wartungsintensive Lösung und soll langfristig die zentrale Plattform für alle Manager werden.

Die Software muss wartbar, erweiterbar und über viele Jahre nutzbar sein.

⸻

2. Projektziele

Die Anwendung soll:

* mehrere Spielzeiten dauerhaft verwalten
* alle historischen Daten speichern
* mehrere Ligen unterstützen
* automatische Tabellen berechnen
* Budgets verwalten
* Marktwerte verwalten
* Transfers verwalten
* Spieltage automatisch auswerten
* News veröffentlichen
* ein einfaches Forum bereitstellen
* einen komfortablen Adminbereich besitzen

⸻

3. Benutzerrollen

Administrator

Kann:

* sämtliche Daten bearbeiten
* Benutzer verwalten
* Wettbewerbe verwalten
* Spielzeiten anlegen
* Einstellungen ändern
* Dateneingaben korrigieren

⸻

Datenpfleger

Kann:

* Spielerdaten erfassen
* Spieltage auswerten
* Marktwerte pflegen
* Ergebnisse eintragen
* News veröffentlichen

Kein Zugriff auf Systemverwaltung.

⸻

Manager

Kann:

* sein eigenes Team verwalten
* seinen Kader ansehen
* Historien ansehen
* News lesen
* Forum benutzen

Kein Zugriff auf Administrationsfunktionen.

⸻

6. Projektgrundsätze

* Keine direkte Programmierung ohne Spezifikation.
* Jede neue Funktion wird zuerst beschrieben.
* Danach wird sie implementiert.
* Danach getestet.
* Danach dokumentiert.
* Danach committed.
